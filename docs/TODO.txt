🛠️  TECHNICAL NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

•  Service Worker (sw.js) v5 — network-first strategy,
   no .html files in cache (Cloudflare returns 308)

•  Cache busting — all JS/CSS files use ?v=12 query
   strings. Bump these when deploying changes.

•  Debounced commit — rapid changes batch into one
   render (30ms window).

•  Lazy rendering — only the active tab renders
   immediately. Other tabs deferred via
   requestAnimationFrame.

•  System fonts — no web font loading. Font stack:
   Inter, system-ui, -apple-system, sans-serif.

•  All buttons have 44px minimum touch targets on mobile.

•  Zero native alert() or confirm() calls remain.

•  File structure:
    index.html      — Main dashboard (862 lines)
    app.js           — Core logic + render functions (2123 lines)
    store.js         — Data store (PGStore) (1157 lines)
    import.js        — Smart import system (1154 lines)
    auth.js          — Authentication (883 lines)
    supabase-storage.js — Cloud sync (348 lines)
    profile.js       — Tenant profiles (404 lines)
    rent.js          — Rent management (378 lines)
    account.js       — Account settings (338 lines)
    sheets.js        — Google Sheets integration
    styles.css       — Base styles + theme (620 lines)
    manage.css       — Management page styles (620 lines)
    mobile-auth.css  — Mobile landing page (695 lines)
    sw.js            — Service worker
    config.js        — Supabase config
